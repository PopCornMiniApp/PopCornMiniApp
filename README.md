# 🍿 PopCorn - Telegram Mini App

A professional movies and TV series Telegram Mini App backed by HuggingFace.

## Features
- 🎬 Movies & TV Series catalog synced from private Telegram group
- 📺 Real video streaming via Telegram Stream Bots
- 🔍 Search and filter content
- ⭐ Detailed pages with cast, story, ratings (TMDB)
- 🗄️ SQLite database stored in HuggingFace Dataset
